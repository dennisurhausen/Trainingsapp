# Trainingsplan Wo 1–14 · Version 27

Web-App für deinen Trainingsplan (Stand: neue Excel vom 20.10.2026).

## Neu in Version 27
- Übungen sind zugeklappt (Name, gemacht / geplant) und gehen beim Antippen auf
- Neuer Tab Statistik: Verlauf pro Übung (geplant und gemacht), Wochen, Kraft-Stände
- Farben und Schrift im Stil von GAINSFIRE (Dunkelgrau, Himmelblau, Roboto)

## Aus Version 4
- Neuer Plan: Satz-Aufteilung (z. B. 3×4) zum Antippen, Landungs-Leiter, neue Reihenfolge, neue Regeln
- Einfacher: fertige Übungen klappen zu, „jetzt“ markiert die nächste Übung, Details unter „⋯ mehr“, Rückgängig-Knopf, Hilfe-Auswahl wie im Turn-Log
- Export: Excel im Format deines Plans (Turn-Log, Gym Plan, Calc, Status, Stufen, Notizen ausgefüllt) plus Blätter App-Auswertung, App-Turnen, App-Gym

## Aktualisieren auf GitHub Pages
Alle Dateien aus diesem Ordner hochladen und die alten ersetzen (auch exceljs.min.js – die wird für den Excel-Export gebraucht).
Deine Einträge bleiben erhalten und werden automatisch auf den neuen Plan übertragen.
